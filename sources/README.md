# OpenGALEN 8 sources

These archives are the unmodified OpenGALEN 8 release (2010-01-28),
redistributed with Erik Sundvall's permission for this browser.
They stay zipped because the OWL functional-syntax tree is about 310 MB
unpacked and the release is easiest to keep intact.

| File | Origin |
|---|---|
| `opengalen8-owl-sources.zip` | https://opengalen.eggbird.eu/download/opengalen8-owl-sources.zip |
| `opengalen8-ascii-sources.zip` | https://opengalen.eggbird.eu/download/opengalen8-ascii-sources.zip |
| `gosl.html` | `OpenGALEN8/gosl.html` extracted from the ascii archive (identical copy is also inside the OWL archive) |

SHA-256 checksums are in `SHA256SUMS`. Downloaded 2026-11-12.

Each archive already carries the GALEN Open Source License and the
per-file copyright notices. Do not strip those notices.

The hierarchy used by the browser is the precomputed dump inside the OWL zip:

`OpenGALEN8/Hierarchy_Dumps/OpenGALEN8_WithPropertyChains_CRM+Diseases+SurgicalProcedures+DrugOntology.dump`

Definitions are read from `OpenGALEN8/OWL_Sources/OWL-F/*.owl`, with extra
GRAIL `topicNecessarily` wording from `OpenGALEN8/GRAIL_Sources/*.grl`.
